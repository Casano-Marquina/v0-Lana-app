┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚀 OPCIÓN 1: USAR LA APP AHORA (PWA)                                         │
└──────────────────────────────────────────────────────────────────────────────┘

1. Abre tu navegador y accede a la URL
2. Busca el botón "Instalar" o espera el prompt
3. Haz clic en "Instalar"
4. ¡Listo! Tienes la app descargada

La app funciona OFFLINE - no necesitas internet después de instalar.

┌──────────────────────────────────────────────────────────────────────────────┐
│ 💻 OPCIÓN 2: DESARROLLAR LOCALMENTE                                          │
└──────────────────────────────────────────────────────────────────────────────┘

# Instalar dependencias
pnpm install

# Iniciar servidor de desarrollo
pnpm dev

# Abre en el navegador
http://localhost:3000

# El servidor se recargará automáticamente cuando hagas cambios

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔨 OPCIÓN 3: BUILD PARA PRODUCCIÓN                                           │
└──────────────────────────────────────────────────────────────────────────────┘

# Compilar
pnpm run build

# Iniciar servidor de producción
pnpm run start

# La app estará en http://localhost:3000

┌──────────────────────────────────────────────────────────────────────────────┐
│ 📋 MI PRIMERA TAREA EN 5 PASOS                                               │
└──────────────────────────────────────────────────────────────────────────────┘

1. 🏠 Abre el Dashboard (página principal)
2. ➕ Haz clic en el botón + (arriba a la derecha)
3. ✍️  Escribe tu tarea:
   - Título: "Aprender Mi Agenda"
   - Ámbito: "Tu Futuro" (púrpura)
   - Prioridad: "Alta" (roja)
   - Fecha: Hoy
   - Hora: Ahora + 5 min
   - Recordatorio: Activado
4. 📤 Haz clic en "Crear Tarea"
5. 🔔 Espera el recordatorio en 5 minutos

│ 🎨 PERSONALIZAR TU AGENDA                                                    │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔔 NOTIFICACIONES Y RECORDATORIOS                                            │
└──────────────────────────────────────────────────────────────────────────────┘

Ir a Configuración ⚙️ y activar:
✓ Notificaciones Push (alertas del sistema)
✓ Sonidos (sonido de alerta)
✓ Recordatorios Visuales (modal en pantalla)

Opciones de recordatorio:
- 5 minutos antes
- 15 minutos antes
- 30 minutos antes
- 1 hora antes
- 1 día antes
- Personalizado (cualquier hora)

┌──────────────────────────────────────────────────────────────────────────────┐
│ 📱 INSTALAR COMO APP EN TU DISPOSITIVO                                       │
└──────────────────────────────────────────────────────────────────────────────┘

iOS (Safari):
1. Abre Safari
2. Accede a la app
3. Toca el icono de compartir 
4. Selecciona "Agregar a pantalla de inicio"
5. Elige nombre y presiona "Agregar"

Android (Chrome):
1. Abre Chrome
2. Accede a la app
3. Toca el menú (⋮)
4. Selecciona "Instalar aplicación"
5. Confirma la instalación

Escritorio (Chrome/Edge):
1. Abre la app
2. Busca el icono de instalación en la barra
3. Haz clic e instala
4. Se abrirá como ventana de app

│ 🔧 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

Las tareas no aparecen:
→ Recarga la página (F5)
→ Verifica el filtro (Hoy/Todas)

No recibo recordatorios:
→ Ve a Configuración → Activa "Notificaciones Push"
→ Autoriza notificaciones en el navegador

La app no funciona offline:
→ Instálala primero como PWA
→ Cárgala completamente una vez con internet

El servidor no inicia:
→ Ejecuta: pnpm install
→ Ejecuta: pnpm run dev
